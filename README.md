# Simple Calculator

A simple, responsive calculator built with HTML, CSS and JavaScript.

## Features
- Addition, subtraction, multiplication and division
- Percentage calculation
- Decimal numbers
- AC and DEL buttons
- Keyboard support
- Responsive design

## Run
Open `index.html` in any modern web browser.

## Tests
Open `tests.html` in any modern web browser to run the automated unit and integration test suite.
